# Electricity Billing System

A Python application that calculates slab-based electricity bills, generates a printable text challan, and saves records to a file.

## Sample Output
```text
consumer name: ghaniya
reference number: 12345
previous reading: 1000
current reading: 1250

"Bijli Bill" 
consumer : ghaniya            Ref: 12345
reading : 1000 -> 1250
units consumed            250
----------------------------------------
energy cost(slabs) Rs    3600.00
fixed/meter charges Rs     200.00
TV licence fee Rs          35.00
GST (17% of energy) Rs     612.00
----------------------------------------
payable within due date Rs    4447.00
payable after due date Rs     4891.70
due date:2026-10-15
```
